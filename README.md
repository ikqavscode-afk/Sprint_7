# Sprint 7 — API-тестирование Яндекс Самокат

Проект содержит автоматизированные API-тесты для сервиса **Яндекс Самокат**.

Тесты проверяют основные API-методы для работы с курьерами и заказами.

## Технологии

* Python 3
* pytest
* requests
* Allure

## Тестируемый API

Базовый URL:

`https://qa-scooter.praktikum-services.ru`

Документация API:

`https://qa-scooter.praktikum-services.ru/docs/`

## Что проверяется

### Курьер

Проверяется:

* создание нового курьера;
* успешное создание курьера;
* авторизация курьера;
* авторизация с неверным логином;
* авторизация с неверным паролем;
* авторизация без обязательного поля;
* проверка ответа сервера и тела ответа.

### Заказы

Проверяется:

* создание заказа с чёрным самокатом;
* создание заказа с серым самокатом;
* создание заказа с двумя цветами;
* создание заказа без указания цвета;
* наличие `track` в ответе при создании заказа;
* получение списка заказов;
* проверка статус-кодов и тела ответа.

Для проверки разных вариантов цвета используется параметризация pytest.

## Установка проекта

Клонировать репозиторий:

```bash
git clone https://github.com/ikqavscode-afk/Sprint_7.git
```

Перейти в директорию проекта:

```bash
cd Sprint_7
```

Создать виртуальное окружение:

```bash
python3 -m venv venv
```

Активировать виртуальное окружение:

```bash
source venv/bin/activate
```

Установить зависимости:

```bash
pip install -r requirements.txt
```

## Запуск тестов

Для запуска всех тестов:

```bash
pytest -v
```

Для запуска тестов с формированием данных для Allure:

```bash
pytest --alluredir=allure-results
```

## Allure

После выполнения тестов сформировать HTML-отчёт:

```bash
allure generate allure-results -o allure-report --clean
```

Открыть отчёт в браузере:

```bash
open allure-report/index.html
```

Папка `allure-results` содержит временные результаты выполнения тестов и не добавляется в Git.

Папка `allure-report` содержит готовый HTML-отчёт и добавлена в репозиторий.

## Очистка тестовых данных

Для тестов создания и авторизации курьера используются фикстуры pytest.

Логин нового курьера генерируется автоматически, поэтому тесты не зависят от заранее созданного пользователя.

После выполнения тестов созданный курьер удаляется.
